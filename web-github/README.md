# فایل‌های اصلاح‌شده وب — Afghan in USA

این دو فایل جایگزین فایل‌های قبلی در مخزن GitHub وب‌سایت می‌شوند:

## ۱. `admin-app-panel.js` (اصلاح‌شده — schema جدید)

### قانون جدید (v12): ورود فقط با ایمیل + رمز

اگر کسی با گوگل وارد شده باشد (حتی مدیر)، پنل جلسه را **پذیرفته و بیرون
می‌اندازد** با پیام: «ورود به پنل فقط با ایمیل و رمز مجاز است.» این قانون
جلوی استفاده کاربران عادی (که در اپ با گوگل وارد می‌شوند) از پنل را می‌گیرد.
حساب مدیر باید از قبل رمز داشته باشد یا از دکمه «رمز را فراموش کرده‌ام» رمز
بسازد.

تغییرات نسبت به نسخه v10:

| بخش | قبلی (ناسازگار) | جدید (مطابق اپ) |
|---|---|---|
| بررسی ادمین | جدول `app_admins` با ستون `active` | جدول `admin_users` (RLS واقعی دیتابیس) |
| اعلان عمومی | ستون‌های `title_fa/body_fa/published` | `title_i18n/body_i18n (jsonb)` + `status='published'` + `published_at` |
| اعلان ویژه پرونده | insert مستقیم با `target_type/target_id` (ستون‌هایی که دیگر وجود ندارند) | RPC امن `notify_case_subscribers` — دیتابیس خودش برای هر مشترکِ فعالِ همان پرونده ردیف می‌سازد |
| اسناد | ستون‌های `title_fa/category/file_name` | `title_i18n/description_i18n/storage_path/size_bytes/status/published_at` |
| لیست پرونده‌ها | فقط ۱۳ پرونده افغانی | هر ۳۰ پرونده: ۱۳ افغانی + ۱۷ ایرانی (با تفکیک نوع در dropdown) |
| سقف فایل سند | ۱۰ مگابایت | ۲۵ مگابایت (مطابق محدودیت دیتابیس) |
| لینک بازیابی رمز | `http://localhost:8080` هاردکد | آدرس خود صفحه (همه‌جا کار می‌کند) |

`supabase-web-config.js` بدون تغییر است (فقط کلید عمومی — هرگز Service Role داخل مرورگر قرار نگیرد).

## ۲. تغییر یک‌خطی در `index.html`

فقط نسخه اسکریپت را بالاتر ببرید تا کش مرورگر بشکند؛ خط ~۱۸۳۰:

```html
<!-- قبل -->
<script type="module" src="admin-app-panel.js?v=11"></script>
<!-- بعد -->
<script type="module" src="admin-app-panel.js?v=12"></script>
```

## پیش‌نیاز در Supabase (یک بار)

1. هر ۷ مایگریشن `supabase/migrations/` اجرا شده باشد (آخری: `20260914000000_admin_case_notify.sql` که RPC `notify_case_subscribers` را می‌سازد).
2. UUID حساب مدیر در جدول `public.admin_users` ثبت شده باشد:
   ```sql
   insert into public.admin_users (user_id) values ('UUID-حساب-شما');
   ```

بدون این دو مورد: ورود موفق است ولی پیام «این حساب در فهرست مدیران نیست» می‌دهید، و ارسال اعلان پرونده خطای `function not found` می‌دهد.
